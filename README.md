# innova-immobiliare-automazioni
Automazioni Make, script CRM e workflow per Innova Immobiliare

## Claude Code Skills

This repo includes the full [Marketing Skills for AI Agents](https://github.com/coreyhaines31/marketingskills) collection by [Corey Haines](https://corey.co), vendored under `.claude/skills/` (MIT licensed, see `.claude/skills/LICENSE`). These give Claude Code specialized knowledge for marketing tasks — copywriting, SEO, paid ads, email, CRO, social, and more — invoked automatically when relevant or directly via `/<skill-name>` (e.g. `/copywriting`, `/seo-audit`).
